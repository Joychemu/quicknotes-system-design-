# QuickNotes System Design

QuickNotes is a full-stack project featuring a robust front-end API client and comprehensive backend architectural documentation designed to scale to 1 million users.

---

## Project Structure
- `index.html`: Main HTML5 document containing structural elements, status paragraphs, and note forms.
- `api.js`: JavaScript application handling asynchronous GET, POST, and DELETE requests against JSONPlaceholder, input validation, state handling, and dynamic DOM rendering.
- `style.css`: Modern stylesheet with clear success, error, and loading states.
- `docs/api-design.md`: Production-ready REST API specification with endpoints, JSON payloads, and error codes.
- `docs/data-model.md`: Relational database schema, entity relationships, SQL statements, and index strategies.
- `docs/architecture.md`: Comprehensive system architecture document covering scale estimations, request flows, diagrams, and trade-offs.
